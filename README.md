# ХАМАГОЧІ
Telegram Mini App / Cloudflare Worker. 8 піксельних звірят, анімація, їжа, ласка, прибирання, сон, ліки, мінігра, монети, дорослішання, смерть і нове життя. Українська мова, ненормативна лексика. Це власні персонажі та графіка, натхненні кишеньковими іграшками 90-х.

## Запуск за кілька хвилин
1. Завантажте **вміст цієї папки** в корінь GitHub-репозиторію.
2. Cloudflare Dashboard → Workers & Pages → Create → Import a repository → виберіть репозиторій.
3. Build command залиште порожнім; Deploy command: `npx wrangler deploy`. Root directory — корінь репозиторію. Якщо потрібно, встановлення залежностей: `npm install`.
4. Worker → Settings → Variables and Secrets → додайте **Secret** `BOT_TOKEN` (токен BotFather). Не додавайте токен у GitHub або frontend. Перезапустіть deployment, якщо панель просить.
5. Worker → Settings → Domains & Routes: використайте виданий `https://pixel-pets.<account>.workers.dev` або додайте власний домен.
6. BotFather → /mybots → ваш бот → Bot Settings → Configure Mini App / Main App: встановіть HTTPS URL Worker. У Menu Button також можна поставити той самий URL. Перевірте запуск саме з кнопки Mini App у Telegram.

Cloudflare Workers Git integration виконує повторний deploy після push. Назва Worker у панелі має збігатися з `name` у `wrangler.jsonc`; за потреби змініть `pixel-pets` у конфігурації.

## Локально
Node.js 22+:
```
npm install
npm run dev
```
У звичайному браузері прогрес зберігається в localStorage. Без токена й Telegram гра працює як локальне демо. У Telegram використовується серверна перевірка initData та Durable Object на користувача. Для локального тесту Telegram покладіть токен у `.dev.vars` як `BOT_TOKEN=...` (файл ігнорується Git).

## Життєвий цикл
Яйце — 3 хвилини, без потреб у догляді. Малюк — 1 година: молоко, швидкий голод і втрата настрою, 💩 кожні 7 хвилин. Не помирає від занедбаності, але вона впливає на характер. Останні 5 хвилин малюк дрімає. Дитина — 2 доби, підліток — 3 доби. Дорослий живе 7–14 діб залежно від зафіксованого при дорослішанні догляду, старість — ще 3 доби. Голод та хвороби можуть завершити життя раніше після стадії малюка. Вік рахується від народження; старі збереження сумісні.

Кожен вид має яйце, малюка, дитину, підлітка, дорослого та старенького. У старості з’являються сивина й окуляри. Поганий догляд змінює вираз обличчя й характер, знижує довголіття. Меню ! виховує пета. Надлишок смаколиків без нормальної їжі погіршує здоров’я та виховання. 💩 накопичується до чотирьох купок і залишається до прибирання. При погладжуванні — усмішка й сердечка, при годуванні — пляшечка або печиво з крихтами, уві сні — Zzz.

## Керування та звуки
Тільки чотири кнопки корпусу: ← / → / ОК / Назад. Піктограми меню не є прямими кнопками дій. Мінігра: 5 разів зловіть жука за 15 секунд, рухаючи курсор стрілками й натискаючи ОК. ☠ завершує життя після окремого підтвердження; за замовчуванням обрано «Ні». Для мертвого пета ОК відкриває вибір нового.

♪ вмикає / вимикає звуки та запам’ятовує налаштування. Синтезовані реакції для їжі, молока, сну, ласки, прибирання й гри відрізняються за видом пета. Аудіо активується після натискання, відповідно до правил браузера.

## Нагадування в Telegram
♧ → ОК → дозвольте боту писати. За замовчуванням вимкнені. Коли показник нижче 70%, ставиться випадкова затримка 10–40 хвилин. Перед надсиланням показники перевіряються знову. Якщо проблему виправлено — нагадування скасовується. Не частіше разу на 3 години, до 3 на місцеву добу; тиша 23:00–09:00 у часовому поясі пристрою на момент увімкнення. Повідомлення має кнопку «До пета». Вимкнути — знову ♧ → ОК. При блокуванні бота доставка зупиняється.

Працює через Durable Object alarms навіть із закритою апкою. Cron, webhook, додаткові бази й секрети не потрібні: використовується існуючий BOT_TOKEN і наявне сховище PETS. Адреса кнопки береться з origin, з якого відкрили Mini App. Ліміти доставки зберігаються до зовнішнього запиту: повторення alarm не спричиняє спаму, але при невизначеному збої окреме нагадування може пропуститись до наступного вікна.

## Перевірки та обмеження
```
npm run check
npm test
npx wrangler deploy --dry-run
```
Мінігра перевіряється на клієнті, монети не мають реальної вартості. Немає платежів, шлюбу та потомства. Нове покоління обирається вручну після завершення життя. Telegram-сесія дійсна до 24 годин — потім перевідкрийте апку. У конфігурації keep_vars зберігає змінні панелі, але BOT_TOKEN все одно слід додавати як runtime Secret, не як build variable.
