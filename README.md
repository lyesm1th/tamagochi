# ХАМАГОЧІ
Telegram Mini App / Cloudflare Worker. 8 піксельних звірят, анімація, їжа, ласка, прибирання, сон, ліки, мінігра, монети, дорослішання, смерть і нове життя. Українська мова, ненормативна лексика. Це власні персонажі та графіка, натхненні кишеньковими іграшками 90-х.

## Запуск за кілька хвилин
1. Завантажте **вміст цієї папки** в корінь GitHub-репозиторію.
2. Cloudflare Dashboard → Workers & Pages → Create → Import a repository → виберіть репозиторій.
3. Build command залиште порожнім; Deploy command: `npx wrangler deploy`. Root directory — корінь репозиторію. Якщо потрібно, встановлення залежностей: `npm install`.
4. Worker → Settings → Variables and Secrets → додайте **Secret** `BOT_TOKEN` (токен BotFather). Не додавайте токен у GitHub або frontend. Перезапустіть deployment, якщо панель просить.
5. Worker → Settings → Domains & Routes: використайте виданий `https://pixel-pets.<account>.workers.dev` або додайте власний домен.
6. BotFather → /mybots → ваш бот → Bot Settings → Configure Mini App / Main App: встановіть HTTPS URL Worker. У Menu Button також можна поставити той самий URL. Перевірте запуск саме з кнопки Mini App у Telegram.

Cloudflare Workers Git integration виконує повторний deploy після push. Назва Worker у панелі має збігатися з `name` у `wrangler.jsonc`; за потреби змініть `pixel-pets` у конфігурації.

## Локально
Node.js 22+:
```
npm install
npm run dev
```
У звичайному браузері прогрес зберігається в localStorage. Без токена й Telegram гра працює як локальне демо. У Telegram використовується серверна перевірка initData та Durable Object на користувача. Для локального тесту Telegram покладіть токен у `.dev.vars` як `BOT_TOKEN=...` (файл ігнорується Git).

## Життєвий цикл
Яйце — 3 хвилини, без потреб у догляді. Малюк — 1 година: молоко, швидкий голод і втрата настрою, 💩 кожні 7 хвилин. Не помирає від занедбаності, але вона впливає на характер. Останні 5 хвилин малюк дрімає. Дитина — 2 доби, підліток — 3 доби. Дорослий живе 7–14 діб залежно від зафіксованого при дорослішанні догляду, старість — ще 3 доби. Голод та хвороби можуть завершити життя раніше після стадії малюка. Вік рахується від народження; старі збереження сумісні.

Кожен вид має яйце, малюка, дитину, підлітка, дорослого та старенького. У старості з’являються сивина й окуляри. Поганий догляд змінює вираз обличчя й характер, знижує довголіття. Меню ! виховує пета. Надлишок смаколиків без нормальної їжі погіршує здоров’я та виховання. 💩 накопичується до чотирьох купок і залишається до прибирання. При погладжуванні — усмішка й сердечка, при годуванні — пляшечка або печиво з крихтами, уві сні — Zzz.

## Керування та звуки
Тільки чотири кнопки корпусу: ← / → / ОК / Назад. Піктограми меню не є прямими кнопками дій. Мінігра: 5 разів зловіть жука за 15 секунд, рухаючи курсор стрілками й натискаючи ОК. ☠ завершує життя після окремого підтвердження; за замовчуванням обрано «Ні». Для мертвого пета ОК відкриває вибір нового.

♪ вмикає / вимикає звуки та запам’ятовує налаштування. Синтезовані реакції для їжі, молока, сну, ласки, прибирання й гри відрізняються за видом пета. Аудіо активується після натискання, відповідно до правил браузера.

## Нагадування в Telegram
♧ → ОК → дозвольте боту писати. За замовчуванням вимкнені. Коли показник нижче 70%, ставиться випадкова затримка 10–40 хвилин. Перед надсиланням показники перевіряються знову. Якщо проблему виправлено — нагадування скасовується. Не частіше разу на 3 години, до 3 на місцеву добу; тиша 23:00–09:00 у часовому поясі пристрою на момент увімкнення. Повідомлення має кнопку «До пета». Вимкнути — знову ♧ → ОК. При блокуванні бота доставка зупиняється.

Працює через Durable Object alarms навіть із закритою апкою. Cron, webhook, додаткові бази й секрети не потрібні: використовується існуючий BOT_TOKEN і наявне сховище PETS. Адреса кнопки береться з origin, з якого відкрили Mini App. Ліміти доставки зберігаються до зовнішнього запиту: повторення alarm не спричиняє спаму, але при невизначеному збої окреме нагадування може пропуститись до наступного вікна.

## Перевірки та обмеження
```
npm run check
npm test
npx wrangler deploy --dry-run
```
Мінігра перевіряється на клієнті, монети не мають реальної вартості. Платежів немає. Можна обрати нове яйце після завершення життя або продовжити покоління через пару для дорослого друга. Telegram-сесія дійсна до 24 годин — потім перевідкрийте апку. У конфігурації keep_vars зберігає змінні панелі, але BOT_TOKEN все одно слід додавати як runtime Secret, не як build variable.

## Особливості видів
Репліки, дотики, їжа й звукові реакції відповідають виду: курочка — пір’ячко й крильця, корівка — ріжки й плямиста спина, жабка — гладенька спинка, динозаврик — луска й шипи. У малюків репліки враховують ще нерозвинені ріжки чи шипи. Молоко дається тільки малюкам ссавців; курчатко отримує зернята, пуголовок — водорості, динозаврик — дрібні шматочки. Дорослим — відповідна їхньому виду піксельна їжа.

## Жива поведінка, звички й покоління
Пет сам гуляє екраном, сідає, дивиться довкола, чухається, позіхає, підстрибує й реагує на 💩. Сон та активні дії мають пріоритет. Налаштування reduced motion вимикає самостійний рух.

Риса характеру: ласкавий / грайливий / сонько / ласун / впертюх. Вона стабільна для старих збережень, впливає на репліки, поведінку й окремі швидкості потреб. Вісім або більше відповідних звичок, зарахованих не частіше однієї на хвилину, можуть змінити рису. Ласкавий отримує більше настрою від погладжування, впертюху потрібно більше виховання.

✥ відкриває вибір із чотирьох мініігор: жучок, падаюча їжа, напрямки, стрибки. Потрібно 5 успіхів до 3 помилок за 25 секунд; винагорода 3 монети. Усі ігри мають піксельне поле й керуються лише кнопками корпусу. Античіт для немонетарних нагород залишається на рівні клієнта.

▤ — альбом із портретом, ім’ям, віком, характером, поколінням і парою. Серверні записи зберігаються окремо й завантажуються сторінками по 20, без видалення старих сторінок. Історія починається з цього оновлення: раніше втрачених петів відновити неможливо. Локальне демо має окремий альбом у браузері. Після смерті стрілки вибирають між новим другом та альбомом; до вибору першого пета Назад також відкриває альбом.

♥ — три створені грою кандидати того самого виду. Це ігрові персонажі, не інші користувачі. Пара доступна дорослому пету з показниками: здоров’я ≥60, їжа/настрій/чистота ≥50, енергія ≥40, не уві сні. Оберіть пару, потім окремо підтвердьте нове покоління. Коротка анімація показує батьків із сердечками; старий пет переходить в альбом, нове яйце успадковує вид і одну з батьківських рис. Лічильник поколінь зростає, монети переходять до нового пета, решта потреб і вік починаються спочатку. Альбом і ліміти нагадувань зберігаються.


## Пам’ять, дім і розпорядок
Меню показує всі 22 менші іконки нерухомою сіткою 8×3. Вибір: ← →, ОК і Назад.

- ⌘ — пам’ять і прив’язаність. Друг рахує повернення після перерви від 30 хвилин, впізнає людину та має улюблену їжу, яку можна відкрити годуванням. Їжа відповідає виду й віку.
- ⏸ — готель на час відпустки з підтвердженням. Потреби, старіння й нагадування на паузі; повернення через те саме меню зберігає вік.
- ◇ — невеликі випадкові пригоди з двома відповідями. Перша через 10–30 хвилин, наступні через 2–6 годин активного перебування вдома; відповідь доступна 6 годин. Вибір змінює настрій, монети або прив’язаність, іноді дає сувенір.
- ⌂ — кімнатка: ліжечко 12 монет (+4 енергії за годину сну), миска 8 (голод на 10% повільніший), рослина 10 (настрій падає на 10% повільніше), іграшка 15 (+3 настрою за гру). Куплені речі видно на екрані; їх можна використати через меню. Рослину можна поливати раз на 5 хвилин.
- ⋈ — родинне дерево, успадкована плямка/смуга/зірочка та родинний сувенір. Меблі й монети переходять до наступного покоління. Дерево показує до 50 вузлів з останніх 1000 архівних записів; решта альбому залишається доступною через сторінки.
- ◷ — добровільний режим дня у часовому поясі пристрою. Налаштовуються сон, пробудження, два прийоми їжі та гра. Три повторення дії в одну годину навчають розклад; вручну обрані години не змінюються автоматично. Ручний сон/підйом має пріоритет 2 години.

Соціальна пісочниця з іншими користувачами до цього оновлення не входить. Кандидати на пару поки створюються грою.


## Маленький світ ☀
Один новий пункт у нерухомому меню відкриває шість розділів. ← → обирають, ОК виконує дію, Назад повертає до розділів. Прогрес зберігається в тому самому Durable Object; додаткових секретів чи міграцій немає.

1. **Форми від догляду.** Для кожного з восьми видів є охайний сяйливий вигляд, округлий сонний і скуйовджений із чубчиком. Підлітки реагують на поточний догляд; доросла форма закріплюється через adultCare. Змінюються силует, деталі й рух. Видові кольори та успадковані мітки збережені.
2. **Ритуали.** Три видові дії з носиком/дзьобиком/лапками, відповідними дотиками й маленькими подарунками. Повторення тричі відкриває улюблений ритуал; пет іноді просить його сам. +7 настрою та +3 прив’язаності, не частіше разу на 5 хвилин. Для малюків ріжки й шипи ще не згадуються у дотиках.
3. **Погода.** Спільна ігрова погода змінюється раз на 3 години: сонце, дощ, хмари, гроза. Піксельне віконце, краплі, блискавка, ковдра та схованка. Короткий звук звучить при відкритті розділу; його можна вимкнути окремо, загальне вимкнення звуку також діє. Реальна геолокація та погодні API не використовуються.
4. **Прогулянки.** Парк, ліс, ставок, сцена й два варіанти дії. Вид має улюблене місце та власну репліку. Вартість: 6 енергії й 3 ситості; потрібно хоча б 15 обох показників. +10 настрою, ще +4 у відповідному місці, +2 прив’язаності, один вибір дає сувенір. Раз на 30 хвилин, вибір протягом 10 хвилин. Повторно отримати нагороду за ту саму подію неможливо.
5. **Заняття.** Купання з бульбашками, догляд за шерстю/пір’ям/лускою чи зволоження жабки, ковдра та трюки. Кожне заняття — три рухи ОК з піксельною анімацією і звуком. Результат після завершення: +8 настрою, +2 прив’язаності; купання очищає й прибирає кал, догляд +12 чистоти, ковдра +5 енергії, трюк −4 енергії та +3 досвіду. Три завершені тренування навчають трюк і відкривають стрибки в поведінці. Перерва 10 хвилин для кожного заняття, незавершене можна продовжити протягом 5 хвилин.
6. **Сни.** Через 2 хвилини сну — хмаринка з видовою картинкою поряд із Zzz. Після пробудження пет розповідає сон; остання історія залишається в розділі снів. Працює також при автоматичному сні за розкладом. Відпустка зупиняє таймери прогулянок, занять, ритуалів і снів.

Це особисті події пета. Спільної пісочниці з реальними гравцями в цьому релізі ще немає.
