# Farewell and quiet sadness

Farewell letters now use longer, species-aware passages, actual used/worn items, positive friendships, learned games and recorded affection. Unknown history is never fabricated. Family handover has its own non-death ending. Existing archived letters remain unchanged; new endings store the new text in the existing archive snapshot.

Opening the end-life menu starts a finite sequence of two (egg/baby) or four (older pets) pleas, spaced 6.5 seconds apart. No state changes occur on opening it. The default option keeps the pet. Alternatives open the existing vacation confirmation (a hotel that pauses age/needs), or a separate final death confirmation, again defaulting to cancel. Back exits immediately and stops the sequence. No fake adoption or rehoming service is claimed.

The pet remains visible and has a slight drooping pose, slow head movement and occasional pixel tear in both graphics modes. The same animation is used during quiet low-mood periods, without interrupting manual actions, sleep or recovery. Tears scale with age and render resolution. The entire dressed sprite moves together. Reduced-motion mode disables animation. Preview state is render-only and is not saved.

Verification: `npm test`, `npm run build`, and the mobile browser flow in `docs/detailed-preview/farewell-check.mjs`.
